# YOLO ve CNN Tabanlı Otonom Trafik Levhası Tanıma

> **Elektrik-Elektronik Mühendisliği | Proje Portfolyosu**

## Proje Hakkında

Trafik levhalarının görüntülerden tanınması için YOLO ve CNN tabanlı yaklaşımları kullanan Python projesi.

## Amaç ve Kapsam

- Trafik levhası veri kümesinin dönüştürülmesi ve eğitim/test olarak ayrılması
- CNN modelinin eğitilmesi ve test edilmesi
- Kamera görüntüleri üzerinde tanıma iş akışının denenmesi
- YOLO tabanlı model dosyalarıyla deneyler

## Kullanılan Teknolojiler ve Konular

- Python
- PyTorch
- Torchvision
- YOLO
- Bilgisayarlı görü

## Çalışmanın Özeti

Depoda `cnn_train.py`, `cnn_test.py`, `convert_ppm.py`, `split_dataset.py` ve `kamera_test.py` gibi betikler yer alabilir. Çalıştırma için veri kümesi ve model dosyalarının uygun konumlarda bulunması gerekir.
